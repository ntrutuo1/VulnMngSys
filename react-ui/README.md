# VulnMngSys Ant Design UI

Modern desktop frontend for VulnMngSys, built with React + Ant Design.

## Run (development)

```powershell
npm install
npm run dev
```

## Build

```powershell
npm install
npm run build
```

Build output is generated to `react-ui/dist` and is embedded into the Windows `.exe` by `build_windows.ps1`.
