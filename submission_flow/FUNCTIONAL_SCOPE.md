# Pham vi chuc nang

## Muc tieu he thong

VulnMngSys ho tro danh gia nhanh cau hinh bao mat cua dich vu tren may local, tap trung vao cac diem kiem tra co the doc tu file cau hinh va ngu canh phien ban.

## Dich vu ho tro

- SSH/OpenSSH.
- Apache HTTP Server.
- Apache Tomcat.

## Nen tang ho tro

- Linux, gom Ubuntu 22.04 va Ubuntu 24.04.
- Windows, gom Windows 11.
- macOS, gom macOS 14.

## Ket qua dau ra

- Trang thai pass/fail tung rule.
- Ly do va bang chung lien quan.
- Hardening index.
- Grade A/B/C/D.
- Canh bao CVE neu co du lieu phien ban.
- Bao cao text trong ban noi bo co the chay.

## Gioi han cua ban xem xet

Ban xem xet khong chua:

- File khoi dong ung dung.
- File cai dependency.
- File build.
- Source raw cua backend/frontend.
- Binary hoac build output.
- Cache/runtime output.

Do do khong the cai dat hay chay lai ung dung tu goi nay.
